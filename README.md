
# FitChef da Nutri 🥗

O **FitChef da Nutri** é uma aplicação web inteligente projetada para transformar desejos gastronômicos em receitas saudáveis, equilibradas e saborosas. Utilizando o poder dos modelos Gemini da Google, o app gera não apenas o passo a passo culinário, mas também imagens apetitosas e informações nutricionais precisas.

## ✨ Funcionalidades

- 🍳 **Geração de Receitas Inteligentes**: Solicite qualquer prato (ex: "Wrap de frango com molho de iogurte") e receba uma versão fit detalhada.
- 🖼️ **Imagens Geradas por IA**: Cada receita acompanha uma foto profissional gerada exclusivamente para o seu prato.
- 📊 **Cálculo de Macros**: Visualize calorias, proteínas, carboidratos e gorduras de cada sugestão.
- 📄 **Exportação para PDF**: Baixe suas receitas favoritas em um formato elegante, pronto para imprimir ou guardar.
- 🕒 **Histórico de Receitas**: Acesse rapidamente as últimas 20 receitas geradas, salvas localmente no seu navegador.
- 💡 **Dica do Dia**: Conselhos diários de nutrição e culinária saudável exibidos no rodapé.
- 📤 **Compartilhamento**: Envie suas descobertas via WhatsApp, Twitter, E-mail ou copie um resumo formatado.
- 🛡️ **Limite Diário**: Controle de uso de até 10 receitas por dia para garantir a melhor experiência.

## 🚀 Tecnologias Utilizadas

- **React 19**: Biblioteca principal para construção da interface.
- **Tailwind CSS**: Estilização moderna e responsiva.
- **Google Gemini API (@google/genai)**:
  - `gemini-3-flash-preview`: Para lógica de criação de receitas e busca de dados nutricionais.
  - `gemini-2.5-flash-image`: Para geração de imagens realistas de alimentos.
- **Lucide React**: Biblioteca de ícones elegantes.
- **html2canvas & jsPDF**: Para conversão de elementos da interface em documentos PDF.
- **LocalStorage**: Para persistência do histórico e contador de uso diário.

## 🛠️ Como usar

1. **Pesquisa**: Digite o nome do prato que deseja "saudabilizar" no campo de busca.
2. **Criação**: Clique em "Criar" e aguarde a IA consultar bases nutricionais e gerar a imagem.
3. **Exploração**: Veja os ingredientes, modo de preparo, macros e a "Dica de Ouro do Chef".
4. **Histórico**: Navegue pelas suas receitas anteriores logo abaixo da receita principal.
5. **Exportação**: Use o botão de download para gerar o PDF oficial da receita.

## 🎨 Design

O app utiliza uma paleta de cores baseada em **Emerald (Esmeralda)** e **Amber (Âmbar)**, transmitindo frescor, saúde e apetitividade. A tipografia combina a modernidade da *Inter* com a elegância clássica da *Playfair Display* para os títulos.
